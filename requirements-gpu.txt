# === GPU Acceleration (CuPy) ===
# CuPy provides GPU-accelerated NumPy-compatible arrays and functions
# Including: cupyx.scipy.ndimage.label for connected component labeling
#
# Works on both Windows and Linux!
#
# Choose ONE based on your CUDA version:
cupy-cuda12x>=12.0.0    # For CUDA 12.x
# cupy-cuda11x>=11.0.0  # For CUDA 11.x (uncomment if needed)

# === GPU Features Provided by CuPy ===
# - Array operations (NumPy compatible)
# - Image downsampling (pyramid building) with pipelined CUDA streams
# - Connected component labeling (cupyx.scipy.ndimage.label)
# - Morphological operations
# - Convolution and filtering
# - np.unique acceleration for large volumes
